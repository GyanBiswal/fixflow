# FixFlow

AI-powered maintenance coordination agent for apartments, hostels, and offices.

Users report maintenance issues, and FixFlow classifies them, checks safety, recommends a technician, and waits for human approval before assigning.

**Status:** under development (Phase 1: project setup).

## Tech stack

Python, LangGraph, LangChain, Groq, FastAPI, Streamlit, MySQL, SQLAlchemy, Pydantic

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
cp .env.example .env   # then fill in your own values
```

More documentation will be added as the project grows.
